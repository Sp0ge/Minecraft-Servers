# KiwyClub — модовая сборка Survival

**Minecraft 1.20.1 · Fabric Loader 0.19.5**. 52 запрошенных проекта; 65 закреплённых файлов с зависимостями.

Клиент импортируется из `ServerData/KiwyClub-Survival-1.20.1.mrpack` в Modrinth App или Prism Launcher. JAR не публикуются в репозитории: загрузчик проверяет SHA-512 из lock-файла.

## Совместимость и эксплуатация

- Survival и PvP используют одинаковые серверные моды и Minecraft 1.20.1. Полный player NBT сохраняет исходную экипировку, включая Cardinal Components/Trinkets.
- Для подключения нужна клиентская сборка. ViaVersion преобразует стандартный протокол, но не игровые моды. Проверка протокола на прокси дополняет проверку совместимости самим Fabric.
- Старые Paper 26.3 миры остаются в `ServerData/survival` и `ServerData/pvp`. Новая версия создаёт отдельный мир в `survival-fabric-1.20.1` и `pvp-fabric-1.20.1`; это новый сезон, автоматического переноса предметов/мира нет.
- Команды установленной версии: `/opac` — личные настройки, `/oclaims` — приваты, `/oparties` — партии; также меню Xaero. Административные подкоманды проверяются самим модом и LuckPerms. Остальные команды скрываются и блокируются для обычных игроков.
- TAB сети управляется Velocity; Styled Player List показывает KiwyClub при входе, периодическое обновление backend отключено большим интервалом, чтобы не перезаписывать сетевой TAB. Чат маршрутизируется модом KiwyClub в радиусе 128 блоков.
- Simple Voice Chat: UDP 24454 Survival и UDP 24455 PvP. На Ubuntu откройте оба порта; `VOICE_PUBLIC_HOST` задаётся в settings.env только при необходимости отдельного публичного имени/IP.
- C2ME имеет 2 потока executor. Экспериментальная параллельная генерация features отключена; остальные штатные оптимизации остаются включёнными. Noisium совместим с C2ME на 1.20.x по документации автора.
- Beta/alpha отмечены в таблице: наличие совместимого релиза не подтверждает отсутствие игровых конфликтов. Клиентский вход, звук, PvP с аксессуарами и переходы по всей сети требуют проверки реальным клиентом. Нагрузочные тесты не выполнялись.
