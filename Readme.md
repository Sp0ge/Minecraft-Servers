# lobby

Сборка запускается из docker-compose.yml ветки main. Настройки генерируются start.py.

Сеть KiwyClub: книга с оглавлением и цветное меню режимов.
IP-лимиты регистрации, входа и подключения AuthMe равны 0.
authme_config.py сохраняет существующие настройки и применяет эти значения
при каждом старте, включая чистый первый запуск.
