# KiwyClub • Твой клуб приключений

**Строй свой дом, побеждай на столбах, проходи новые трассы и вызывай друзей на дуэль.**
Survival • Pillars • Parkour • PvP — одна сеть, один аккаунт и единый вход.

## Запуск из main

Скачайте ZIP ветки `main`, распакуйте его и откройте терминал в этой папке.

```bash
bash start.sh
```

На Ubuntu скрипт подготовит Docker, если он отсутствует, загрузит файлы с проверкой
SHA-256/SHA-512, соберёт компоненты и запустит сеть. Для установки Docker нужны права sudo.
Python 3 при отсутствии устанавливается через apt. На Mac установите и запустите Docker Desktop,
затем выберите экономный локальный профиль:

```bash
bash start.sh --local
```

Подключение локально: **localhost:25565**. Профиль Ubuntu слушает `0.0.0.0:25565`;
для внешнего доступа откройте TCP 25565 и UDP 24454 (голосовой чат через Velocity).
Первое создание миров занимает несколько минут. Скрипт включает принятие Minecraft EULA;
запускайте его при согласии с [EULA Minecraft](https://www.minecraft.net/eula).

**По умолчанию все данные проекта находятся в `./ServerData`:**

| Папка | Содержимое |
|---|---|
| `source/` | Распакованные исходники компонентов |
| `assets/` | Проверенные серверные JAR и шаблоны карт Pillars и lobby |
| `lobby/` | Лобби и аккаунты AuthMe |
| `survival-fabric-26.3/` | Новый модовый Survival и игроки |
| `parkour/`, `pvp-fabric-26.3/`, `proxy/` | Данные соответствующих серверов |
| `duels-fabric/` | Исходные инвентари с модовыми компонентами и записи дуэлей |
| `survival/`, `pvp/`, `duels/` | Сохранённые данные прежней Paper-сети |
| `arenas/` | Временные миры Pillars, удаляются после опустошения |
| `backups/` | Резервные копии Survival перед вайпом |
| `secrets/`, `state/`, `plugins/` | Секреты, расписание, собранный общий плагин |
| `settings.env` | Настройки ресурсов, порта и обслуживания |

Для другой папки: `DATA_ROOT=/путь/к/данным bash start.sh`.
Повторный запуск сохраняет миры, аккаунты и настройки. При обновлении архива
компонентов контейнеры пересоздаются, чтобы загрузить новую версию плагина. При переходе с прежней версии
импорт из старых остановленных томов `mcservers_*` включается только явно:
`MIGRATE_LEGACY_VOLUMES=true bash start.sh --local`. Старые тома сохраняются.
Удаление тестового `ServerData` создаёт чистую сборку при следующем запуске.

Основная ветка содержит `Readme.md`, `docker-compose.yml`, `start.sh`, `.gitignore`
и `network-sources.tar.gz`. В архив включены исходники компонентов, иконка и чистый
шаблон скачанной карты; данные игроков и секреты в него не входят. Для запуска ZIP
не требуется Git или скачивание дополнительных веток. Исходники для разработки
сохраняются в отдельных ветках; архив в main соответствует их текущему состоянию.

## Survival 26.3: новая сборка и настройки

Minecraft 26.3, Fabric Loader 0.19.5, Java 25. Сервер: 21 внешний мод и KiwyClub Network. Клиент: 8 внешних модов и проверка KiwyClub.

## Геймплей

- Ванильные предметы, мобы и бой. Artifacts, Better Combat, Lootr, Friends & Foes, YUNG’s, OPAC и прежние игровые расширения исключены.
- Генерация Overworld: Terralith + Tectonic; End: Nullscape. Nether ванильный. Существующий рельеф сохраняется, новая генерация действует в новых чанках; на границах возможны переходы.
- Simple Voice Chat работает через Velocity; Sound Physics Remastered устанавливается только на клиент. Controlify и YACL сохранены для геймпадов.
- Уровни чар — до технического предела 255. Сняты конфликты чар/предметов и запрет «Слишком дорого». Оплата опытом сохраняется, торговля жителей не меняется.

## Удобство

- AppleSkin — подсказки о насыщении еды; клиент + сервер.
- Mouse Tweaks — удобное перемещение предметов; только клиент.
- Shulker Box Tooltip — просмотр содержимого шалкеров; клиент.
- Double Doors — парное открытие обычных дверей; сервер. Рекурсивное открытие, люки и калитки выключены. Зависимость: Collective.

## Оптимизация

Lithium, FerriteCore, Krypton, Alternate Current, ServerCore, C2ME, VMP; Chunky для предварительной генерации и spark для диагностики. ModernFix и Noisium не включены: версий для Fabric 26.3 нет.

C2ME использует 2 потока. Chunky включён: радиус 640 блоков, 60 секунд ожидания без игроков, 30 секунд работы / 60 секунд отдыха; при входе игрока — пауза. Пауза пустого Survival отключена. Перезапуск в 05:00 МСК и квартальный вайп с новым сидом сохранены.

## Права и команды

LuckPerms создаёт управляемую группу `kiwy-player`, наследуемую `default`. Разрешены узлы `kiwy.command.<команда>`, `voicechat.listen`, `voicechat.speak`, `voicechat.groups`. Права администратора игрокам не выдаются.

Обычные команды Survival: `/home`, `/tpa`, `/tpaccept`, `/tpdeny`, `/pvp`, `/pvpaccept`, `/pvpdeny`; сетевые `/server`, `/help`, `/voicechat`. В PvP доступна `/pvpleave`. Прокси скрывает лишние корневые команды, сервер блокирует их выполнение.

Административные операции выполняются через консоль/RCON. Для доверенного администратора создайте отдельную группу с `kiwy.admin=true` и конкретными необходимыми правами LuckPerms; не выдавайте `*` группе `default`.

## Новый мир

Сборка создаёт новый Survival при первом запуске. Перенос мира 1.20.1 и конвертация модовых блоков не требуются. Новый мир сразу генерируется с Terralith + Tectonic и Nullscape.

Данные: `ServerData/survival-fabric-26.3`, `ServerData/pvp-fabric-26.3`, `ServerData/duels-fabric-26.3`. Старые каталоги 1.20.1 не используются и не блокируют запуск. В ZIP сборки игровые данные, аккаунты и секреты не входят.

Обычный запуск `bash start.sh` сохраняет уже созданный мир 26.3. Новый сид назначается при создании мира и при плановом вайпе.

## Проверка аккаунта и скины

**Вход только с лицензионным Minecraft Java-аккаунтом:** Velocity работает в
`online-mode=true` и проверяет сессию Mojang. AuthMe остаётся дополнительным паролем
в лобби. Скин берётся из вашего Minecraft-профиля и передаётся на все режимы через
Velocity modern forwarding вместе с официальным UUID и подписанными текстурами.
После изменения скина в профиле переподключитесь к сети. Кастомный TAB сохраняет
исходные профили игроков, поэтому не заменяет их скины.

На backend-серверах `server.properties: online-mode=false` является штатной
настройкой прокси: проверку выполняет Velocity. При этом у каждого Paper
`proxies.velocity.online-mode=true`, forwarding включён и защищён общим секретом;
подключаться следует только через опубликованный порт Velocity.
`force-key-authentication=false` оставлен для совместимости поддерживаемых клиентов;
проверка лицензионной сессии включена независимо от этого параметра.

**Переход с прежнего offline-режима меняет UUID игроков.** Старые файлы игроков
сохранены, но официальный профиль не получает автоматически вещи и прогресс старого
UUID. Для переноса существующего прогресса нужна отдельная миграция после проверки
соответствия аккаунтов; существующие профили не перезаписываются по совпадению ника.

## Режимы и команды

- **Лобби:** японская карта `by-kubj-lobby-japan-free`, игроки видят друг друга,
  всегда день и ясная погода. Каждый новый вход в сеть начинается в лобби;
  каждый вход в лобби возвращает к общему безопасному спауну. Книга «Команды и режимы»
  с оглавлением, компас с меню. `/register <пароль> <повтор>`, `/login <пароль>`,
  `/changepassword <старый> <новый>`, `/logout`.
- **Выбор:** `/server lobby`, `/server survival`, `/server parkour`, `/server pillars`.
  `/help` — красивое меню справки; `/help all` — все команды;
  `/help account|survival|pillars|parkour|pvp` — отдельный раздел.
- **Survival 26.3 Fabric:** первый спаун разбросан по квадрату 64×64 чанка.
  Survival остаётся запущенным и продолжает обработку загруженных миров при нулевом
  онлайне. В серверном модуле отключён таймер бездействия сущностей ServerLevel 26.3.
  Для работы механизмов в удалённых базах нужны загруженные чанки, например через
  /forceload (консоль администратора). Выгруженные чанки не симулируются. Ежедневный перезапуск
  в 05:00 МСК и сезонный вайп сохраняются.
  Обычный повторный вход сохраняет позицию. После смерти без действующей кровати спаун распределяется
  снова. `/home` возвращает к текущей действующей кровати; `/tpa <ник>`, `/tpaccept`,
  `/tpdeny` — запрос перехода на 60 секунд. Чат виден в том же мире на расстоянии
  до 128 блоков (8 чанков). Сообщения о входах и смертях видны всему Survival.
- **Обслуживание Survival:** ежедневно в 05:00 МСК с предупреждениями за 20, 10 и
  5 минут; вайп через каждые три календарных месяца. Перед вайпом — резервная копия;
  новый сезон всегда получает другой сид. Сохраняются аккаунты, мир и вещи сбрасываются.
  В локальном профиле обслуживание выключено; в Ubuntu включено.
- **Pillars 1.21.10:** карта Ур—Мур Studio v1.0.6, до 16 игроков на арене.
  Все пять арен запускаются вместе с сетью и остаются включёнными. `/server pillars`
  выбирает свободную арену; `/server pillars_1` … `/server pillars_5` — конкретную.
  В идущий матч прямой переход допускается как наблюдатель. После последнего выхода
  только опустевшая арена перезапускается с чистой копией карты. Во время сброса
  она временно недоступна; остальные продолжают работать. Не посещённая пустая арена
  не удаляется по таймеру. Скрытый резерв больше не создаётся; прежний пустой резерв
  удаляется при обновлении. Общий лимит сети остаётся 64 игрока.
- **Parkour:** один общий сервер без отдельной квоты игроков. Случайная трасса из
  80 прыжков с нарастающей сложностью: длинные прямые и диагональные прыжки,
  перепады высоты, одиночные площадки и ледяные участки после 40-го прыжка.
  Максимальный прямой промежуток — 4 блока; подъёмы и ледяные участки короче.
  Голод не мешает спринту. Контрольные точки проходятся по порядку, каждые 10; `/checkpoint`, `/restart`. Трасса обновляется
  каждый час и сразу после первого прохождения. Победитель объявляется в чате всей
  сети, все участники возвращаются на старт новой трассы, старые контрольные точки
  сбрасываются. Одновременное касание финиша даёт одного победителя.
- **PvP:** из Survival `/pvp <ник>`, `/pvpaccept`, `/pvpdeny`; на арене `/pvpleave`.
  Запрос действует 60 секунд; дуэль — до 10 минут на отдельном поле 3×3 чанка
  (48×48 блоков вместе со стенами). Перед каждой дуэлью генерируются новый рельеф,
  укрытия и оформление. Стартовые стороны зеркальные, между ними остаётся проход.
  Стены высотой 8 блоков и невидимая верхняя граница удерживают игроков на поле;
  карта защищена от разрушения, взрывов, огня и размещения жидкостей.
  Используются копии вещей. После боя исходный инвентарь, броня, опыт и расходники
  восстанавливаются полностью, оба игрока возвращаются в Survival. Выход/сдача —
  поражение; отмена, ничья и перезапуск не объявляют победителя.
  Вся сеть видит «Игрок <имя> выиграл <имя> в PVP».

**Общий лимит сети — 64 игрока. Ограничения регистрации и подключений с одного IP
отключены.** В TAB: цветной KiwyClub, текущий сервер, игроки сети и сервера, пинг.
Команды игрока ограничены справкой, переключением, авторизацией и командами режима;
посторонние административные команды скрыты и блокируются при выполнении.

## Подготовка чанков

На Survival установлен **Chunky Fabric 1.5.3**. При `CHUNK_PREGEN_ENABLED=true`
подготавливается квадрат радиусом 640 блоков вокруг зоны появления игроков.
Генерируется только Overworld, без установки границы мира и без загрузки всего мира.

Для HDD: ожидание 60 секунд без игроков, работа сеансами по 30 секунд с отдыхом
не менее 60 секунд. Условия: TPS ≥19.5, средний MSPT <35, свободно более 20 ГиБ.
Вход игрока сразу ставит задачу на паузу; ухудшение показателей проверяется раз в 10 секунд.
В обоих профилях функция включена; отключение — `CHUNK_PREGEN_ENABLED=false`
в `ServerData/settings.env`. После перезапуска продолжается сохранённая задача.

C2ME использует 2 потока executor. Предгенерация сокращает
работу при первом исследовании; фактическое ускорение и чтение с HDD не измерялись.

Проверить прогресс через консоль:

```bash
docker exec mcservers-controller python /app/rcon.py survival "chunky progress"
```

Команды Chunky обычным игрокам недоступны. Сохранённые задачи — в
`ServerData/survival-fabric-26.3/config/chunky`, состояние подготовки сезона — в
`ServerData/survival-fabric-26.3/kiwy-chunky.json`.

## Проверка сборки в lobby

При подготовке PvP игрок временно фиксируется на месте. Коррекция позиции
отправляется только при изменении координат и не чаще четырёх раз в секунду:
ответ клиента на телепортацию не вызывает следующую телепортацию.
После завершения боя оба участника видят «Победитель PvP: имя. Проигравший: имя»
перед возвращением в Survival. Вся сеть получает сообщение «Игрок имя выиграл
имя в PVP». Если бой отменён или время истекло, участникам сообщается, что
победителя нет.

Pillars сообщает результат всей сети: в одиночном режиме — ник победителя,
в командном — красная/синяя команда и имена её оставшихся игроков. Если никто
не выжил, сообщается об отсутствии победителей. Результат берётся из функций
окончания матча оригинальной карты до очистки команд и игровых тегов; повторные
попытки доставки одного результата не создают повторного глобального сообщения.
Служебная команда результата скрыта от игроков и не принимает их прямые вызовы.

Японский lobby освещён невидимыми блоками `minecraft:light` уровня 15:
подсветка покрывает свободные пространства над поверхностями карты, включая
внутренние помещения и крыши. Освещение включено в шаблон мира и применяется
при импорте карты; предыдущая версия lobby сохраняется в `lobby/map-backups`.

Parkour: постоянная ночь (`18000`), смена времени и погоды отключена.
Трасса, старт, контрольные точки и финиш подсвечены невидимыми блоками
`minecraft:light` уровня 15. При смене трассы прежние источники света удаляются,
а новая трасса получает свою подсветку автоматически.

При первом входе в lobby Velocity запрашивает у клиентского мода `kiwy_client_checker`
SHA-512 файлов модов, фактически загруженных Fabric. Список обязательных клиентских
файлов формируется из `mods.lock.json`; требуются точные версии текущей сборки.
Дополнительные моды не мешают проверке. Проверяются 8 файлов для Fabric 26.3.

Если мод проверки отсутствует, ответ не получен или файлы отличаются, игрок видит
кликабельную ссылку [Скачать сборку KiwyClub](https://sp0ge.ru:3000/s/KiwyClubMRPack).
До успешной проверки закрыты переходы в Survival и PvP. Lobby, Pillars и Parkour
доступны после обычной авторизации. Ссылка также есть в `/help` и книге.

`bash start.sh --local` автоматически собирает клиентский мод и вкладывает его
в `ServerData/KiwyClub-Survival-26.3.mrpack`. **Замените файл по ссылке этим новым
`.mrpack`**: старые сборки без мода проверки не подтвердят наличие модов.
Игрок должен импортировать обновлённый файл в лаунчер и переподключиться.
Это проверка совместимости по ответу клиента, а не механизм против модифицированных клиентов.
