# Parkour

Paper 26.3, общий пустой мир со случайной трассой на 80 прыжков.
Новая трасса каждый час и сразу после прохождения; победитель объявляется всей сети, контрольные точки через 10 прыжков.
/checkpoint — к последней точке; /restart — к началу.
При падении игрок возвращается к контрольной точке.
Отдельной квоты нет, действует общий лимит сети 64 игрока.
Трасса сохраняется в постоянном томе; общий плагин собирается в infra-controller.
Запуск описан в main:Readme.md.
