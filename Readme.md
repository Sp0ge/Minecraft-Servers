# lobby

Сборка запускается из docker-compose.yml ветки main. Настройки генерируются start.py.

Сеть KiwyClub: книга с оглавлением и цветное меню режимов.
Японская карта экспортирована из исходной схемы 1.20.4 и загружается Paper 1.21.11.
Переданный готовый мир имел метку 26.3 без необходимых файлов генерации;
его не понижаем до 1.21.11. Оригинальные схемы сохранены в `schematics/`.
Безопасный спаун шаблона: 87, 43, 114. Игроки видят друг друга.
Постоянный день, ясная погода, режим adventure и защита постройки.
При каждой новой сессии Velocity выбирает lobby. AuthMe также возвращает на спаун
после авторизации и не сохраняет позицию выхода. Замена шаблона сохраняет
прежние миры в `ServerData/lobby/map-backups/`; аккаунты не затрагиваются.
IP-лимиты регистрации, входа и подключения AuthMe равны 0.
authme_config.py сохраняет существующие настройки и применяет эти значения
при каждом старте, включая чистый первый запуск.
